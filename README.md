# Titanic Exploratory Data Analysis (EDA)

## Project Overview
This project explores the Titanic passenger dataset using Python to identify patterns in passenger survival, age, gender, passenger class, and numerical variables.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Dataset overview and statistical summary
- Missing-value analysis
- Passenger survival count
- Survival by gender
- Age distribution
- Age distribution by passenger class
- Correlation heatmap

## Key Findings
- More passengers died than survived.
- Female passengers had a higher survival rate than male passengers.
- The dataset includes passengers from different age groups and classes.
- The visualizations help explore relationships between passenger characteristics and survival.

## Conclusion
This project demonstrates basic Exploratory Data Analysis using Python, statistical summaries, and data visualizations.
